// =============================================================================
//  Ukrainian.
//
//  Two kinds of entry, and the difference matters:
//
//  1. KEYED entries, for strings with no natural English sentence to key on -
//     the language selector's own labels.
//
//  2. SENTENCE entries, which are everything else. The key is the English
//     sentence itself, byte for byte as it appears in PluginEditor.cpp, and the
//     value is its translation. xlat() looks up whatever it is handed, so a
//     tooltip is written once, in English, where it is used - and translating it
//     is one line here. See the note above xlat() in PluginEditor.cpp.
//
//  A sentence with no entry shows its English. That is deliberate: a
//  half-translated plugin is better than one that shows the user a raw key, and
//  an untranslated tooltip is the honest state of a work in progress rather
//  than a bug. Add a line per sentence as it gets translated.
//
//  The keys below are the shared interaction hint and the parameter tooltips
//  the panel shows first: the MACHINE page, the new DYNAMICS page, and the
//  NEURAL model picker. Each key is copied exactly from its xlat() call in the
//  source, so it is looked up byte for byte; the remaining tooltips follow the
//  same pattern and can be added a line at a time.
//
//  The transient shaper's two tooltips carry a dash in ATK / SUS because both
//  controls are BIPOLAR and centred: negative softens or shortens, positive
//  sharpens or lengthens. A translation that lost that would leave the user
//  turning a knob with no idea which way does what.
// =============================================================================
